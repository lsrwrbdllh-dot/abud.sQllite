# حالة التحقق من تطبيق Android

بتاريخ 2026-10-21:

| الفحص | النتيجة |
| --- | --- |
| اختبارات محرك SQLite الأصلية | 35 ناجحة |
| اختبارات واجهة الربط المحلية للجوال | 20 ناجحة |
| المجموع | 55 ناجحة |
| مطابقة الجداول والحقول مع PRAGMA | 68 جدولاً، 412 حقلاً |
| اعتماد المستندات | 21 نوعاً في المحرك، إضافة إلى القيد اليدوي وعكسه وتثبيت الجرد |
| القيود والحماية | المخطط الأصلي نفسه، مع 280 trigger |
| تركيب Java | اجتاز JavacTask.parse على JDK 21؛ هذا ليس بناء Android |
| بناء APK | متوقف قبل تنزيل Gradle بسبب `java.net.SocketException: Operation not permitted` |
| تشغيل APK على هاتف أو محاكي | لم ينفذ بعد |

تختبر طبقة الربط نفس أوامر JSON التي يستدعيها Android. مرّت الحركات العشرين في المثال الأصلي عبر هذه الطبقة، مع اختبارات إضافية لفروق الجرد والتوصيل واستبعاد الأصل والتمويل اليدوي والعكس، ومنع تعديل القيود والأرصدة والآثار المرحّلة، ومنع تكرار الاعتماد، ومطابقة النسخ المستعادة وحماية القاعدة الحالية عند رفض الاستيراد. فحص هذه الطبقة لا يثبت صلاحية حزمة APK أو تشغيل Chaquopy على Android.

يوفر `.github/workflows/android-mobile.yml` البناء بواسطة Gradle وAndroid SDK واختبار تثبيت وتشغيل في وضع الطيران على محاكي، وإنشاء متجر وتصنيف ثم إعادة التشغيل والتحقق من استمرار البيانات. لا توصف حزمة APK بأنها جاهزة حتى ينجح البناء والاختبار الفعلي ويظهر artifact.
