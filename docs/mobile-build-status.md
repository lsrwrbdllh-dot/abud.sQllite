تختبر طبقة الربط نفس أوامر JSON التي يستدعيها Android. مرّت الحركات العشرين في المثال الأصلي عبر هذه الطبقة، مع اختبارات إضافية لفروق الجرد والتوصيل واستبعاد الأصل والتمويل اليدوي والعكس، ومنع تعديل القيود والأرصدة والآثار المرحّلة، ومنع تكرار الاعتماد، ومطابقة النسخ المستعادة وحماية القاعدة الحالية عند رفض الاستيراد. أكمل اختبار المحاكي التحقق من تشغيل Chaquopy وSQLite داخل حزمة APK نفسها.

يوفر `.github/workflows/android-mobile.yml` البناء بواسطة Gradle وAndroid SDK واختبار تثبيت وتشغيل في وضع الطيران على محاكي، وإنشاء متجر وتصنيف ثم إعادة التشغيل والتحقق من استمرار البيانات. نجح البناء والاختبار ونشر [artifact القابل للتنزيل](https://github.com/lsrwrbdllh-dot/abud.sQllite/actions/runs/39538959851/artifacts/12318736561).
